- 西瓜视频：读取相同视频编号的头条公开播放器，保留原始西瓜网页作为回退，并检查编号一致。

- Dailymotion：增加逐片下载和设备端 MP4 封装能力（未加密、编码连续 MPEG-TS，64 MB 内），固定媒体回归测试通过。但新部署仍无法稳定取得平台分片，线上验证未通过，未列入可用平台。暂停后重新下载合并。
- 哔哩哔哩仍对本轮云端请求返回 412；YouTube、Facebook、Reddit 要求账号或验证；Vimeo 的测试请求仍受登录/访问限制。未绕过验证，未把这些平台改为可用。

完整样例、SHA-256、编码和时长见 [JSON 证据](platform-verification.json)。Instagram 样例本身无音轨，其余通过样例均有音频。

## 重新验证

```bash
pip install -r requirements-verify.txt
playwright install chromium
export SHIYING_VERIFY_URL=https://your-deployment.example
python scripts/verify_platforms.py
# 审阅报告后再发布平台状态：
python scripts/update_platform_catalog.py
```

需要本机安装 ffmpeg / ffprobe。有部署保护时，通过环境变量 `SHIYING_VERIFY_BYPASS` 传入测试凭据；不要写进文件或提交。脚本不记录媒体票据、Cookie 或凭据，临时下载文件在检查后删除。
