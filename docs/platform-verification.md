## 重新验证

安装项目 Python 依赖和 ffmpeg，在仓库根目录运行：

```bash
export SHIYING_VERIFY_URL=https://your-deployment.example
python scripts/verify_platforms.py
```

若部署有访问保护，通过受信任的环境变量 `SHIYING_VERIFY_BYPASS` 提供测试凭据；不要写入源码。脚本不会把凭据、媒体票据、Cookie 或下载视频保存到仓库。报告写入 `docs/platform-verification.json`，媒体在临时目录验证后删除。

本轮快手依据当前引擎和项目源码均无专用适配作出判断；没有伪造视频请求来声称已验证快手下载。
